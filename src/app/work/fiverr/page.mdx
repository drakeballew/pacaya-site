## Overview

Having been embedded within [CreativeLive's](https://www.creativelive.com/) email marketing team for over 5 years, we noticed an opportunity to streamline the design-to-development workflow for their newsletter operation.

Each of CreativeLive's newsletters is custom designed, but the layout from an HTML/CSS perspective was generally very similar, with the moving parts being the Class, Instructor, URL, and Image Alt Text. 

CreativeLive's Design team uses Bynder for digital asset management, which we leveraged to check job status and retrieve design files，passing them to Pipedream and using OpenAI to retrieve the relevant information from them and return a best guess as to which Class, Instructor, URL, and Alt Text make the most sense for each asset. We then use that info to build the email in Iterable and send us a notification when it's ready for review.

This workflow has removed almost all sources of error within the development portion of the design-to-development workflow. Prior to building this out, campaigns could be developed late or get lost, URLs would be misassigned to the wrong asset, the HTML/CSS would break due to missing tags, the list goes on. The error rate for the newsletter program at CreativeLive is now functionally 0% thanks to this improved workflow.
